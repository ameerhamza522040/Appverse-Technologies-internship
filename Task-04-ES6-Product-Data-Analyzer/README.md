# 🚀 ES6 Product Data Analyzer

A mini frontend project developed as part of the **Appverse Technologies Frontend Development Internship** under **Phase 1 – Web Foundations & JavaScript Mastery**.

This project demonstrates how modern **ES6+ features** and **JavaScript Array Methods** can be used to analyze product data in a clean, practical, and beginner-friendly way.

---

## 📌 Project Objectives

- Practice ES6+ JavaScript concepts
- Work with structured product data
- Perform data analysis using array methods
- Display results dynamically in the browser
- Build a small real-world JavaScript application

---

## ✨ Features

- 📦 Dataset containing **20 product objects**
- 📝 Uses **Object Destructuring**
- 🔄 Uses **Spread Syntax**
- 🗺️ Uses **map()**
- 🔍 Uses **filter()**
- ➕ Uses **reduce()**
- 🎯 Uses **find()**
- ✅ Uses **some()**
- ✔️ Uses **every()**
- 📊 Generates a **Summary Object**
- 🌐 Displays all results dynamically in the browser

## 📚 Array Methods Demonstrated

| Method | Description |
|---------|-------------|
| **map()** | Creates a new array by transforming existing data |
| **filter()** | Filters products based on a condition |
| **reduce()** | Calculates the total inventory value |
| **find()** | Finds a specific product |
| **some()** | Checks whether at least one product satisfies a condition |
| **every()** | Checks whether all products satisfy a condition |
