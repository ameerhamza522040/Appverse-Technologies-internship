# 🚀 TaskFlow – CSS Design Token System

TaskFlow is a fictional **Software as a Service (SaaS)** landing page developed as part of my **Frontend Development Internship at Appverse Technologies**. The purpose of this project is to demonstrate how a scalable and reusable **CSS Design Token System** can be implemented using HTML, CSS, and JavaScript.

---

## 📌 Project Overview

This project focuses on building a reusable design system by using **CSS Custom Properties (Design Tokens)** instead of hardcoded design values. The interface is designed to be clean, responsive, and easy to maintain while supporting both **Light** and **Dark** themes.

---

## ✨ Features

* 🎨 CSS Design Token System
* 🌈 Color Tokens
* 🔤 Fluid Typography using `clamp()`
* 📏 8-Point Spacing Scale
* 🔲 Border Radius Tokens
* 🌑 Shadow Tokens
* ⚡ Animation Timing Tokens
* 🧩 Reusable UI Components
* 🌙 Light & Dark Theme Switching
* 📱 Responsive Design
* ♿ Semantic HTML Structure
* 🏷️ BEM Naming Convention

---

## 🧩 Components

The project includes three reusable UI components:

* Primary Button
* Pricing Card
* Login Form

Each component is styled using the shared design tokens to maintain consistency throughout the interface.
